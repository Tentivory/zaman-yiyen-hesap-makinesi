# ⏳️ Zaman Yiyen Hesap Makinesi

## Bu Repo Nedir?

Bu, insanlığın en büyük sorunlarından birine çözüm arayan devrim niteliğinde bir projedir: **Hesaplamaların çok hızlı yapılması**.

Evet, modern bilgisayarlar 2+2'yi nanosaniyelerde hesaplıyor. Bu kabul edilemez. Bu repo, zamanı yiyerek, her hesaplamayı bir destana, bir bekleme savaşına, bir varoluşsal yolculuğa dönüştürür.

**Neden var?** Çünkü acele iş eşek öldürür. Ve biz eşekleri seviyoruz.

## Özellikler

- 🐋 **Zaman Yeme**: Her işlemde rastgele saniyeler bekler. Kahvenizi için.
- 📝 **Üst Makam Onayı**: Hesaplama öncesi bürokratik onay simülasyonu.
- 🎭 **Felsefi Mesajlar**: Her işlemin derin anlamı vardır (ya da yoktur).
- 😱 **Sıfıra Bölme Krizi**: Varoluşsal hata yönetimi.
- 🚀 **Gerçekten Çalışır**: Python ile yazıldı, terminalde çalıştırın.

## Nasıl Kullanılır?

```bash
python zaman_yiyici.py
```

Varsayılan olarak 2 + 2 hesaplar. Daha fazla için kodu düzenleyin. Ama acele etmeyin. Asla.

## Katkıda Bulunma

Pull request açabilirsiniz ama onay süreci 3-5 iş günü sürebilir. Üst makamlara bağlı.
